## [Talos Linux Image Factory](https://factory.talos.dev/)

Terraform creates a schematic automatically for Talos v1.14.5,
including the official `iscsi-tools`, `util-linux-tools`, and `qemu-guest-agent`
extensions required by Longhorn and the Proxmox guest agent. It then retrieves
the Secure Boot ISO and installer URLs from Image Factory; no schematic ID or
image URL needs to be copied into tfvars.

## Cluster networking

The Talos configuration disables the built-in Flannel CNI and kube-proxy.
Install the [`k8s/cilium`](https://github.com/luiscosta18/k8s/tree/main/cilium)
Helm chart before deploying workloads. It enables the Gateway API controller
and exposes listeners through host networking because the cluster has no
LoadBalancer implementation. Attach application `HTTPRoute` resources to the
Cilium GatewayClass.

The chart settings follow the [Cilium Talos installation
guidance](https://docs.cilium.io/en/stable/installation/k8s-install-helm/#talos-linux):
kube-proxy replacement through Talos KubePrism, Talos-compatible cgroup
handling, legacy host routing for Talos DNS forwarding, and no `SYS_MODULE`
capability. Gateway API requires the [standard Gateway API
CRDs](https://docs.cilium.io/en/stable/network/servicemesh/gateway-api/gateway-api/).
The [Talos default-hardening guide](https://docs.siderolabs.com/talos/v1.14/security/talos-default-hardening-and-cis-compliance)
also describes security controls Talos enables by default.

Metrics Server and kube-state-metrics are intentionally not installed by this
Terraform example; install them after Cilium.

## Longhorn storage

Each control-plane and worker node receives a separate 40 GB virtual disk.
Talos provisions `/dev/sdb` as a `/var/mnt/longhorn` user volume. Install
Longhorn separately after Cilium, using `/var/mnt/longhorn` as its data path:

```bash
helm repo add longhorn https://charts.longhorn.io
helm repo update
kubectl create namespace longhorn-system
kubectl label --overwrite namespace longhorn-system \
  pod-security.kubernetes.io/enforce=privileged
helm upgrade --install longhorn longhorn/longhorn \
  --namespace longhorn-system \
  --set defaultSettings.defaultDataPath=/var/mnt/longhorn
```

The privileged Pod Security Admission label is limited to Longhorn's namespace,
as required by [Longhorn's Talos support guide](https://longhorn.io/docs/latest/advanced-resources/os-distro-specific/talos-linux-support/).
Verify that `/dev/sdb` is the dedicated secondary disk in your VM before
applying; the Talos volume selector intentionally targets that disk.

## Talos API access from Kubernetes

The control-plane configuration allows the `os:etcd:backup` Talos API role
only to pods in the `talos-backup` namespace. This least-privilege
`KubeTalosAPIAccessConfig` is applied with the other control-plane patches.
After applying Terraform, install the official backup CronJob and configure
its S3 credentials and age encryption key using the
[`k8s/talos-backup` instructions](https://github.com/luiscosta18/k8s/tree/main/talos-backup).

## Security notes

Talos includes secure defaults such as an immutable OS and no SSH. This example
uses Secure Boot assets and does not disable Proxmox TLS certificate
verification. Restrict access to Talos API TCP/50000 and Kubernetes API
TCP/6443 with your Proxmox/network firewalls. Terraform state contains Talos
cluster secrets and sensitive outputs: keep it private, encrypted at rest, and
access-controlled. Review the [Talos security checklist](https://docs.siderolabs.com/talos/v1.14/security/talos-security-checklist)
and [default hardening guide](https://docs.siderolabs.com/talos/v1.14/security/talos-default-hardening-and-cis-compliance)
for production use.

## Get talosconfig and kubeconfig

```bash
terraform output -raw kubeconfig > ~/.kube/config
terraform output -raw talosconfig > ./talosconfig
```

## Talosctl - Dashboard + Health

```bash
export TALOSCONFIG="$PWD/talosconfig"

talosctl dashboard

talosctl version
talosctl get members
talosctl etcd status
```

## Talosctl - upgrade talos + k8s version

```bash
curl -Lo talosctl https://github.com/siderolabs/talos/releases/download/v<talos_version>/talosctl-linux-amd64
chmod +x talosctl
sudo mv talosctl /usr/local/bin/talosctl
```

```bash
terraform output -raw talos_installer_image

talosctl upgrade \
  --nodes <node_ip> \
  --image "$(terraform output -raw talos_installer_image)"
```

```bash
talosctl upgrade-k8s --to <kubernetes_version> --nodes <cp_ip>
```
